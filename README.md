# Study Track

日々の勉強時間と学習ノートを記録する、日本語のカレンダー PWA。

## 機能

- 開始・終了時刻から分数を自動計算。複数の時間帯・日をまたぐ勉強にも対応
- カレンダーには合計の分数を表示。月別の勉強時間・勉強日数・連続記録も集計
- 日付ごとのノート、見出し・太字・箇条書き・チェックリスト、プレビュー、ノート検索
- ライト／ダークモード。初回は端末の設定に追従
- 端末内保存、JSON バックアップの書き出し・読み込み
- スマホ対応、ホーム画面へのインストール、初回読み込み後のオフライン利用

## 開発

Node.js 24（外部の実行時依存パッケージなし）。

```sh
npm start        # ポート3000で起動。PORTで変更可能
npm test         # 時間計算とバックアップ検証
npm run build    # dist/に静的ファイルを生成
```

`public/` がソース。ビルドにパッケージのダウンロードやAPIキーは不要です。

## 無料公開

推奨は **公開リポジトリの GitHub Pages（無料）**。有料プラン・独自ドメイン・サーバー契約は不要です。

1. このコードをリポジトリの `main` に反映する。
2. GitHub の Settings → Pages → Build and deployment → Source で **GitHub Actions** を選ぶ。
3. Actions の「Test and deploy free GitHub Pages」を実行する（以降 main の更新時に自動実行）。
4. デプロイ結果に表示される HTTPS URL を開く。

ルートドメインにも `/Study-Track-App/` のようなサブパスにも対応しています。非公開リポジトリの場合、無料 Pages を使うには公開が必要になる場合があります。公開設定の変更や有料プランの契約は自動で行いません。

別の選択肢は Cloudflare Pages の無料プランへ `dist/` をアップロードする方法です。Functions、データベース、有料アドオンは使いません。

## スマホへのインストール

公開した **HTTPS URL** を一度オンラインで開いてください。

- iPhone / iPad：Safari の共有メニュー →「ホーム画面に追加」。
- Android：Chrome のメニュー →「ホーム画面に追加」またはアプリ内のインストールボタン。

ストアへの登録や有料の開発者アカウントは不要です。アプリのキャッシュ準備後はオフラインでも記録できます。実機やOSによってインストール操作は異なります。

## 保存とバックアップ

アカウントは不要で、記録をサーバーへ送信しません。ブラウザのローカルストレージに保存します。端末・ブラウザ・公開URLを変えると記録は共有されません。自動の端末間同期はありません。

ブラウザのデータ消去、シークレットモードの終了、OSによるストレージ削除などで記録を失う可能性があります。定期的に「データをエクスポート」でバックアップしてください。別の端末では「データをインポート」で復元できます。日時は利用中の端末のローカル時刻で扱います。同じ開始・終了時刻は0分、終了時刻が早い場合は翌日として計算します。

## 検証済み

Node の計算・バックアップ検証テスト、および Chromium で記録の保存・再読み込み、ノート書式とHTMLの無害化、検索、テーマの保持、390pxのスマホ表示、オフライン再読み込みを検証。実機へのインストールと本番ホスティングへの公開は、公開先で別途確認してください。
